# BiciRuta-web

Diagnostico de la tienda web de bicicletas de la compañía BiciRuta S.L.

La estructura de este proyecto es:

```text
BiciRuta/
├── css/estilos.css
├── img/logo-biciruta.png
├── js/app.js
├── .gitignore
├── index.html
└── README.md
```

Para verlo con la extensión "Live Server", hay que pulsar el botón "Go Live" en la parte inferior derecha del Visual Studio Code. Esto abrirá automaticamente una ventana del navegador con la página web en desarollo.

Para acceder manualmente, se puede escribir "http://localhost:5500/index.html" en la barra de URL.
